# Línea del tiempo CUH

Línea del tiempo interactiva con hitos institucionales que aparecen al desplazarse.

## Tecnologías

- HTML
- CSS
- JavaScript

## Instalación y ejecución

Abre `index.html` con Live Server o en el navegador.

## Uso

Desplázate para recorrer los hitos.
